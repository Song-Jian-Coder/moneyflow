# MoneyFlow 首页模块实施提案

## 变更动机

MoneyFlow 项目需要实现首页模块，为用户提供资金流向可视化分析的核心入口。首页是用户接触产品的第一界面，需要直观展示申万行业板块的资金流向，帮助用户快速锁定主力进攻方向。

## 预期收益

1. **用户价值**：用户可在 30 秒内锁定今日主力资金进攻方向，快速做出交易决策
2. **业务价值**：建立产品核心功能入口，为后续行业资金流、大盘资金流、AI 助手等功能提供导航
3. **技术价值**：验证前端数据可视化能力，为后续复杂图表开发积累经验

## 变更内容

本次变更实现 MoneyFlow 首页的 8 个独立开发单元：

### 1. Hero 区品牌主视觉
- 品牌背景图展示
- 品牌标语（主标语 + 副标语）
- 搜索框入口

### 2. 功能导航栏
- 三大功能入口卡片：行业资金流、大盘资金流、AI 助手
- 每个卡片包含图标、标题、一句话描述
- 点击跳转到对应功能页面

### 3. 时间维度切换器
- 快捷时间选择（今日、昨日、近 7 日、近 30 日）
- 自定义时间范围
- 驱动数据自动聚合计算

### 4. 申万行业树状图
- 树状图（Treemap）展示申万板块-一级-二级-三级-股票层级
- 面积编码（成交额）+ 颜色编码（主力净流入）
- 支持逐级下钻和面包屑导航
- 处理股票归属问题（仅属于二级行业的股票挂在"未分三级"下）

### 5. 申万二级行业热力图
- 热力图展示所有申万二级行业
- 色块面积 = 成交额
- 色块颜色 = 主力净流入（红=流入，绿=流出）
- 支持点击触发板块详情

### 6. 板块详情面板
- 展示板块基本信息和成分股列表
- 支持成分股排序（成交额、净流入、涨跌幅）
- 支持面板打开、关闭、拖动

### 7. 数据更新时间显示
- 展示最后更新时间戳
- 标注"每日收盘后更新"

### 8. 响应式布局与移动端适配
- 支持手机/平板/PC 多端访问
- 触摸手势（缩放/拖动）
- 移动端导航菜单适配

## 影响范围

### 受影响的模块

- **前端**：新增首页相关组件和页面
- **后端**：新增行业数据、资金流数据相关 API 接口
- **数据库**：新增行业数据表、资金流数据表（需另行设计）

### 不受影响的模块

- Todo 模块（已独立运行）
- 用户认证模块（MVP 阶段暂不实现）

## 技术方案

### 前端技术栈

- **框架**：Next.js (App Router) + TypeScript
- **样式**：Tailwind CSS
- **图表库**：ECharts 或 D3.js（树状图/热力图）
- **状态管理**：React Context（时间选择器状态）
- **数据请求**：React Query 或 SWR

### 后端技术栈

- **框架**：Spring Boot 3.2.5 + Spring Data JPA
- **数据库**：H2（开发）/ MySQL（生产）
- **数据聚合**：后端提供聚合后的数据接口

### 数据依赖

本次变更需要以下数据支持（数据来源待确定）：

1. **申万行业层级数据**：板块-一级-二级-三级-股票的层级关系
2. **行业资金流数据**：各行业的成交额、主力净流入、涨跌幅等
3. **股票资金流数据**：各股票的成交额、主力净流入、涨跌幅等
4. **数据更新时间**：最后数据更新时间戳

> **注意**：数据来源和采集方案需另行设计，本提案仅定义前端展示规范。

## 回滚方案

### 前端回滚

- 删除首页相关组件和页面
- 恢复原有首页（如有）
- Git 回滚到变更前的 commit

### 后端回滚

- 删除新增的 API 接口
- 数据库表结构回滚（通过 Flyway 迁移文件）
- Git 回滚到变更前的 commit

### 数据回滚

- 行业数据和资金流数据为只读数据，不影响业务数据
- 如需回滚，直接删除相关数据表即可

## 风险与缓解

### 风险 1：数据来源不确定

**影响**：可能导致开发过程中无法获取真实数据进行测试

**缓解措施**：
- 使用 Mock 数据进行开发和测试
- 提前与数据提供方沟通数据接口规范
- 设计数据适配层，便于后续接入真实数据

### 风险 2：大数据量渲染性能

**影响**：树状图和热力图可能需要渲染 100+ 个节点，性能可能不佳

**缓解措施**：
- 使用 Canvas 渲染（数据量大时）
- 实现虚拟滚动和分层加载
- 进行性能测试和优化

### 风险 3：移动端触摸手势复杂度

**影响**：触摸手势实现复杂，可能影响开发进度

**缓解措施**：
- MVP 阶段仅实现基础手势（缩放、拖动）
- 使用成熟的触摸手势库（如 `react-swipeable`）
- 充分测试不同设备和浏览器
