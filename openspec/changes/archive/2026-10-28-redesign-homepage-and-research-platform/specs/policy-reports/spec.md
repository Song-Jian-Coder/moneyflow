# Spec Delta

## Purpose

提供政策报告聚合能力，后端自动爬取产业政策报告、工作会议报告等经济类报告并分类入库，前端在 `/policy-reports` 页面展示报告列表、支持分类筛选和详情查看。

## ADDED Requirements

### Requirement: 政策报告数据模型
后端 SHALL 定义政策报告实体，包含以下字段：报告标题、报告摘要、报告分类（产业政策、工作会议、宏观经济等）、来源机构、发布日期、原文链接、PDF/文档URL、创建时间、更新时间。所有字段使用驼峰命名（camelCase）。

#### Scenario: 报告实体创建
- **WHEN** 系统爬取到一份新的政策报告
- **THEN** 系统创建报告实体，填充标题、摘要、分类、来源、日期等字段，并持久化到数据库

### Requirement: 政策报告爬取
后端 SHALL 提供定时任务或手动触发机制，从预设的数据源自动爬取经济类政策报告。爬取内容包括报告标题、摘要、分类、来源机构、发布日期和文档链接。

#### Scenario: 定时爬取执行
- **WHEN** 定时任务触发（如每日凌晨执行）
- **THEN** 系统从预设数据源爬取最新政策报告，去重后入库，返回爬取结果统计（新增数、跳过数、失败数）

#### Scenario: 爬取去重
- **WHEN** 爬取到的报告标题和来源与已有记录匹配
- **THEN** 系统跳过该报告，不重复入库

### Requirement: 政策报告分类
后端 SHALL 支持对政策报告进行分类管理。预置分类包括：产业政策、工作会议、宏观经济、金融监管、财政政策、货币政策。系统 SHALL 支持根据报告内容自动分类或手动指定分类。

#### Scenario: 自动分类
- **WHEN** 新报告爬取入库时
- **THEN** 系统根据报告标题和摘要的关键词自动匹配预置分类，无法匹配时归入「其他」分类

### Requirement: 政策报告列表 API
后端 SHALL 提供分页查询政策报告列表的 API，支持按分类筛选、按发布日期排序。响应格式遵循 `Result<T>` 统一响应规范。

#### Scenario: 分页查询报告列表
- **WHEN** 前端请求 `GET /api/policy-reports?page=1&size=20&category=产业政策`
- **THEN** 后端返回分页的报告列表，包含标题、摘要、分类、来源、发布日期等字段

#### Scenario: 无筛选条件查询
- **WHEN** 前端请求 `GET /api/policy-reports?page=1&size=20` 不传分类参数
- **THEN** 后端返回所有分类的报告列表，按发布日期降序排列

### Requirement: 政策报告详情 API
后端 SHALL 提供根据报告 ID 查询报告详情的 API。响应包含报告的所有字段信息。

#### Scenario: 查询报告详情
- **WHEN** 前端请求 `GET /api/policy-reports/{id}`
- **THEN** 后端返回该报告的完整详情，包括标题、摘要、分类、来源、发布日期、文档链接等

#### Scenario: 报告不存在
- **WHEN** 请求的报告 ID 不存在
- **THEN** 后端通过 BusinessException 抛出业务异常，HTTP 200 + 自定义错误 code

### Requirement: 政策报告前端页面
前端 SHALL 在 `/policy-reports` 路由下展示政策报告页面，包含分类筛选栏和报告列表。报告列表每项展示标题、摘要、分类标签、来源机构和发布日期。

#### Scenario: 展示报告列表
- **WHEN** 用户访问 `/policy-reports` 页面
- **THEN** 页面展示分类筛选栏和报告列表，默认显示最新报告

#### Scenario: 分类筛选
- **WHEN** 用户点击分类筛选栏中的「产业政策」
- **THEN** 报告列表刷新，仅展示产业政策分类的报告

#### Scenario: 查看报告详情
- **WHEN** 用户点击报告列表中的某条报告
- **THEN** 页面展示该报告的完整详情，包括标题、摘要、分类、来源、发布日期和文档下载/外链

#### Scenario: 空状态展示
- **WHEN** 某分类下暂无报告数据
- **THEN** 页面展示空状态提示「暂无相关政策报告」
