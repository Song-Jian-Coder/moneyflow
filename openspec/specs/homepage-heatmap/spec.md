# Homepage Heatmap Specification

## Purpose

以热力图形式展示申万二级行业板块的资金流向，通过色块面积和颜色编码直观展示各行业的成交额和主力净流入情况，帮助用户快速识别资金流向。

## Requirements

### Requirement: 热力图展示
前端 SHALL 以热力图形式展示所有申万二级行业，通过面积编码成交额、颜色编码资金流向方向。

#### Scenario: 初始视图
- **WHEN** 页面加载完成且数据请求成功
- **THEN** 展示所有申万二级行业色块（约 100+ 个）
- **AND** 每个色块面积与其成交额成正比
- **AND** 每个色块颜色根据主力净流入方向着色（红=流入，绿=流出）
- **AND** 色块内显示行业名称和净流入额

#### Scenario: 面积编码
- **WHEN** 展示热力图
- **THEN** 每个色块面积与其成交额成正比
- **AND** 成交额越大的色块面积越大
- **AND** 所有色块面积之和等于容器总面积

#### Scenario: 颜色编码 — 流入
- **WHEN** 行业的主力净流入 > 0
- **THEN** 色块使用红色系着色
- **AND** 净流入金额越大，红色越深

#### Scenario: 颜色编码 — 流出
- **WHEN** 行业的主力净流入 < 0
- **THEN** 色块使用绿色系着色
- **AND** 净流出金额越大（绝对值），绿色越深

### Requirement: 热力图交互
前端 SHALL 支持点击和悬停交互，并提供图例说明。

#### Scenario: 点击色块
- **WHEN** 用户点击某个行业色块
- **THEN** 触发 onIndustryClick 回调
- **AND** 传递行业代码 industryCode 作为参数

#### Scenario: Hover 效果
- **WHEN** 用户鼠标悬停在某个色块上
- **THEN** 色块边框高亮（白色边框，2px）
- **AND** 显示 tooltip 展示关键信息
- **AND** 鼠标指针变为手型（pointer）

#### Scenario: 图例展示
- **WHEN** 热力图展示
- **THEN** 在热力图旁边或底部展示颜色图例
- **AND** 图例显示红色=流入、绿色=流出的含义
- **AND** 图例说明色块面积代表成交额

### Requirement: 热力图异常处理
前端 SHALL 在数据为空或色块面积过小时提供降级展示和自适应文字显示。

#### Scenario: 行业数量为 0
- **WHEN** 数据返回的行业列表为空
- **THEN** 显示空状态提示"暂无行业数据"
- **AND** 显示默认占位图

#### Scenario: 最小可见面积
- **WHEN** 某行业成交额极小，计算面积 < 40x40px
- **THEN** 色块面积设置为最小可见面积
- **AND** 色块内不显示文字

#### Scenario: 色块文字自适应
- **WHEN** 色块面积 >= 80x80px
- **THEN** 色块内显示行业名称和净流入额
- **WHEN** 色块面积 40x40px - 80x80px
- **THEN** 色块内仅显示行业名称
- **WHEN** 色块面积 < 40x40px
- **THEN** 色块内不显示文字，仅通过 tooltip 展示
