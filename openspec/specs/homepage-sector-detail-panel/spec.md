# Homepage Sector Detail Panel Specification

## Purpose

提供板块详情面板，当用户点击热力图或树状图中的行业或股票色块时，弹出详情面板展示板块基本信息和成分股列表，支持排序和下钻。

## Requirements

### Requirement: 板块详情展示
前端 SHALL 在用户点击热力图或树状图中的行业色块时，弹出详情面板展示板块基本信息和成分股列表。

#### Scenario: 打开面板 — 行业板块
- **WHEN** 用户点击某个行业色色块
- **THEN** 详情面板从右侧滑入或居中弹出
- **AND** 显示行业名称、代码、层级、所属上级行业
- **AND** 显示关键指标：成交额、主力净流入、涨跌幅、成分股数量
- **AND** 显示成分股列表，默认按主力净流入降序排列

#### Scenario: 成分股列表排序
- **WHEN** 用户点击列表表头（如"成交额"、"净流入"）
- **THEN** 列表按该字段重新排序
- **AND** 首次点击为降序，再次点击切换为升序
- **AND** 表头显示排序箭头标识

### Requirement: 面板交互
前端 SHALL 支持多种方式关闭详情面板，并在数据异常时提供降级展示。

#### Scenario: 关闭面板
- **WHEN** 用户点击面板的关闭按钮（X）
- **THEN** 面板关闭，动画流畅

#### Scenario: 点击外部关闭
- **WHEN** 用户点击面板外部区域（遮罩层）
- **THEN** 面板关闭

#### Scenario: 按键关闭
- **WHEN** 用户按下 ESC 键
- **THEN** 面板关闭

### Requirement: 面板异常处理
前端 SHALL 在板块数据不存在或为空时提供降级展示。

#### Scenario: 板块不存在
- **WHEN** 传入的板块 ID 不存在
- **THEN** 面板显示错误提示"板块不存在"
- **AND** 提供关闭按钮

#### Scenario: 成分股数量为 0
- **WHEN** 该板块下无成分股数据
- **THEN** 列表区域显示空状态提示"该板块暂无成分股数据"
